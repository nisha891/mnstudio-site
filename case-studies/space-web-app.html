Space web app: the control room behind every conversation.

Space lets companies put live audio on their own website. The widget is what visitors see. The web app is where the company’s team signs up, installs the widget, creates and hosts audio rooms, takes 1:1 calls with customers and looks back at who joined. We designed it end to end.

The brief

One place to run every audio conversation.

The widget only works if the people behind it can set it up and run it without help. Space needed a web app that takes a company from sign-up to its first live room, then gives the team what it needs during and after every conversation.

It is used by two kinds of people. Admins, often founders, marketers or product leads, install the widget, style it, schedule rooms and invite the team. Team members in sales and support answer customers who call in from the website, with the customer’s details beside the call.

The web app covers four jobs:

01

Get set up

Create an account, install the widget with one snippet and switch features on.

02

Run live rooms

Schedule a room, host it, bring listeners on stage and answer questions.

03

Talk 1:1

Answer customers waiting on the website and pull in a teammate when needed.

04

Learn from it

See who registered, who joined and when, and keep recordings in one place.

Design decisions

Powerful for the team, calm to use.

Show the result while you set it up

Every widget setting has a live preview beside it, so admins see what visitors will see before they save.

Simple first, advanced on request

A room needs only a title and a time. Permissions, ribbons, audio quality and locked rooms stay under “Advanced settings”.

The customer beside the conversation

In 1:1 calls, the customer’s role, company and order history sit next to the call, so sales and support never go in cold.

No dead ends

Empty dashboards, recordings and chats each explain what goes there and offer the one action that fills them.
